📋 Spec – Pálya-adatlapok 1–3 (MVP-A)

A rendszerterv-osszeadas-kivonas-100.html 6.2 / 14. szakaszának kibontása az első három pályára. Ezek a konkrét számok, amikből a PALYAK blokk épül. A 4–7. pálya külön adatlapon, később.

Melyik 3 pálya legyen az MVP-A: az 1–3 (bontás → 10 → 20, ezt javaslom), vagy a 4–6 (a 100-as kör). Ez az adatlap az 1–3-ra készült.

0. Közös szabályok (mindhárom pálya)

  • Minden pálya: tema:"erdo", gyujtemeny:"erdei". Az első állomás mindig { nev:"Rajt" } (nincs feladat), az utolsón cel:true.
  • Feladatszám egy állomáson = darab (felmondásnál mindig 1 teljes bontás).
  • Ismétlés-kerülés: egy állomáson belül nincs két azonos feladat. Összeadásnál a (a,b) és a (b,a) ugyanaz.
  • Korlátok: összeg ≤ eredmeny_max; különbség ≥ 0; minden szám 0–100.
  • Tízesátlépés definíció — összeadás: (a%10) + (b%10) ≥ 10; kivonás: (a%10) − (b%10) < 0 (kölcsönkérés).
  • atlepes kulcs: "nincs" → a generátor újragenerál, míg nincs átlépés; "kell" → míg van; "lehet" → bármelyik.
  • Nehézség csak az itt megadott állomás-tartományokból jön – nincs dinamikus alkalmazkodás (rendszerterv 2.5, 11.2).

5. Generátor-elvárás (a FELADATGENERATOR-hoz)

osszeadas.ujKerdes(cfg):
  ismételd:
    a = veletlen(cfg.a_min, cfg.a_max)
    b = veletlen(cfg.b_min, cfg.b_max)
  amíg NEM ( a+b <= (cfg.eredmeny_max||100)
            ÉS atlepesOK(a, b, "+", cfg.atlepes)
            ÉS nem_volt_mar_ezen_az_allomason(a,b) )
  vissza { szoveg:a+" + "+b+" = ?", felolvasando:"Mennyi "+szo(a)+" meg "+szo(b)+"?",
           helyes:a+b, tipp1:..., tipp2:..., naplo:{tipus:"osszeadas",a,b,helyes:a+b,atlepes:atlepesE(a,b,"+")} }

kivonas.ujKerdes(cfg): mint fent, de b <= a garantált, és atlepesOK(a,b,"-",cfg.atlepes)

szambontas: valasztSzam(cfg) = cfg.szam ?? veletlen(cfg.szam_min, cfg.szam_max)

  a meglévő motor teljes_bontas mintája.
