🔊 Spec – Hang és beszéd

Felolvasó-szövegsablonok, magyar számfelismerés 0–100, a bontás elfogadási szabálya, mikrofon-engedély folyamat, és a hangeffektek. Ez a projekt technikailag legkockázatosabb része – ezért a részletes spec.

1. Felolvasás (Text-to-Speech)

  • API: window.speechSynthesis, utterance.lang = "hu-HU", a legjobb elérhető magyar hang; ha nincs magyar hang, az alapértelmezett is felolvassa a számokat érthetően.
  • rate = 0.95, pitch = 1.0. Új mondat előtt speechSynthesis.cancel().
  • Minden felolvasás offline működik (a hang a gépben van).
  • „🔊 Halld újra" gomb mindig látszik a játékképernyőn: a legutóbbi feladat-mondatot ismétli.

A számokat a felolvasónak szóban adjuk át (pl. „negyvenhét"), nem számjegyként – így minden hangon jól szól. A szám→szó függvény a meglévő motor szamSzoval()-ja kibővítve 100-ig.

2. Beszédfelismerés (a válasz elsődleges módja)

  • API: window.SpeechRecognition || window.webkitSpeechRecognition, lang = "hu-HU", interimResults = false, maxAlternatives = 3, continuous = false.
  • Folyamat: „🎤 Mondom" → egy felismerési menet (max ~6 mp, aztán auto-stop) → a 3 alternatívából számokat nyerünk ki → értékelés.
  • Támogatás: Chrome / Edge (asztali) → megy. Firefox / Safari → nincs SpeechRecognition → automatikus beírás mód.

Értékelés:
  • Mind a 3 alternatívát parszoljuk; a válaszból az első értelmes számot vesszük.
  • Ha valamelyik alternatíva száma = a helyes válasz → elfogadva.
  • Ha van szám, de egyik sem jó → hibás próba (számít a hibaszámba).
  • Ha egyik alternatívában sincs szám → „Nem hallottam, mondd még egyszer" – NEM számít hibának, a mikrofon újra figyel.
  • Félrehallásokat (pl. „hét"~„hat") nem javítunk; a 3 alternatíva általában megoldja.

2.2 Számbontás – a felmondás elfogadási szabálya (véglegesítve 2026-09-02, kódban: bontasFelmondOk())

A gép ad egy N számot (1 ≤ N ≤ 10). A gyereknek egyben, egyfolytában, lentről fölfelé fel kell mondania N minden bontását:

0 + N ,  1 + (N−1) ,  2 + (N−2) ,  … ,  N + 0        →  összesen N+1 sor

Példa N = 5: „nulla meg öt, egy meg négy, kettő meg három, három meg kettő, négy meg egy, öt meg nulla" — mind a 6 sor, ebben a sorrendben.

Mit néz a gép, mit nem

  • A felismert szövegből csak a számokat szedjük ki, sorban (a meglévő szamokKinyer()). Minden más szó figyelmen kívül marad: „meg", „plusz", „és", „hozzá", „egyenlő", „az", „lesz", „is", „annyi mint", szünet, vessző — bármelyik, bármilyen kombináció.
  • A kimondott összeg (a sor végén az „= N" rész) elhagyható, és soronként külön-külön: van, ahol kimondja, van, ahol nem — vegyesen is jó.
  • A szám lehet tőszám („öt") vagy ragozott („ötöt", „öttel") — a parszer tőszámként veszi.

Egy sor elfogadható alakjai

Amit a gyerek mondKinyert számokJó?
„nulla meg öt"[0, 5]✔ (csak a két tag)

Az egész felmondás akkor JÓ, ha…

a kimondott számlista pontosan ez — i = 0 … N-re egymás után: 
[ i , N−i ]   és utána OPCIONÁLISAN egy   [ N ]   (a kimondott összeg)
  • egyetlen sor sem hiányozhat (a 0 + N és a záró N + 0 is kell);
  • a sorok sorrendje kötött: lentről (az első tagok pontosan 0, 1, 2, …, N);
  • minden sorban a második tag pontosan N − első tag;
  • a végén nem maradhat „idegen" szám (a lezáró kimondott összeg még belefér).
A gép a kimondott összeget „mohón" fogyasztja, de az utolsó előtti sornál (i = N−1) meghagy egy N-et a záró N + 0 sor első tagjának — így az N = 2 eset (ahol az összeg és az utolsó sor első tagja is 2) is jól megy.

Hibás / hiányos felmondás

  • A gép megmondja, hány sort mondott el hibátlanul az elejéről: „Eddig jó volt 3 sor. Mondd el újra az egészet, lentről kezdve!" — a lista alsó (kész) sorai zölden látszanak.
  • A felmondást egyben kell megismételni (nem onnan folytatja, ahol elakadt) — a lentről-fölfelé gyakorlás a lényeg. Nincs pontlevonás.
  • 2. sikertelen próba után lépésenkénti (beírós) módra vált: N+1 kis kérdés, „{N} = {i} + ?", a billentyűzeten.
  • Ha egyik felismerési alternatívában sincs szám → „Nem hallottam" — nem hibás próba, a mikrofon újra figyel.
  • Mind a 3 felismerési alternatívát végignézzük; ha bármelyik JÓ → elfogadva. Ha nem, a legtöbb elejéről-jó sort adó alternatíva számít a visszajelzésben.

Parszer-részlet a felmondáshoz

„tíz egy" ≠ 11. A tízes+egyes összeolvasás (pl. „húsz egy" → 21) csak 20-tól él. A „tíz" utáni külön egyes két önálló szám marad, mert a bontás felmondásában gyakori: „…nulla meg tíz, egy meg kilenc…".
A tényleges ellenőrző (rövidítve) 
function bontasFelmondOk(nums, N) {
  var p = 0;
  for (var i = 0; i <= N; i++) {
    if (nums[p] !== i)     return { ok:false, sorok:i };  p++;   // első tag
    if (nums[p] !== N - i) return { ok:false, sorok:i };  p++;   // második tag = N-i
    if (i < N - 1)        while (nums[p] === N) p++;             // kimondott összeg(ek)
    else if (i === N - 1) { var db=0; while (nums[p+db]===N) db++;   // hagyj egyet
                            while (db-- > 1) p++; }
  }
  while (nums[p] === N) p++;                     // záró kimondott összeg
  if (p !== nums.length) return { ok:false, sorok:N };   // idegen szám maradt
  return { ok:true, sorok:N + 1 };
}

2.3 Mikrofon-engedély folyamat

  1. Az első „🎤 Mondom"-nál a böngésző felugró engedélykérése jelenik meg.
  2. Engedélyezve → onnantól működik, nincs újabb kérdés.
  3. Elutasítva vagy nincs API → átváltás beírásra + egyszeri kedves üzenet (felolvasva is): „Most beírással játszunk. A mikrofont a szülő bekapcsolhatja a beállításban."
  4. A Szülői nézetben „Alap válaszmód: beszéd / beírás" (alap: beszéd), és látszik, hogy a böngésző támogatja-e a beszédet.
  5. A beállítás localStorage-ban (valaszmod kulcs), gyerekfüggetlen (a gépé).
A kivonás felolvasása: „Vegyél el {b}-t {a}-ból. Mennyi marad?" – vagy inkább a rövidebb „{a} mínusz {b}. Mennyi?" A lenti tippek az előbbihez igazodnak.
