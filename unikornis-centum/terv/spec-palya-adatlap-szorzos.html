📋 Spec – Pálya-adatlapok: Szorzós liget (A–D)

A rendszerterv 2.2b / 6.2 kibontása a 4 szorzós-osztós pályára – ezekből épül a PALYAK szorzós blokkja és a GEN új típusai. Az 1–3. pálya adatlapjának (spec-palya-adatlap-1-3.html) mintájára. Minden szám kiindulási javaslat, az első playteszten hangoljuk.

0. Közös szabályok (mind a négy pálya)

  • Az első állomás mindig { nev:"Rajt" } (nincs feladat); az utolsón cel:true.
  • Feladatszám = darab (a felmondásnál mindig 1 teljes tábla).
  • Teljes szorzótábla: a szorzó/tábla 1–10, a másik tényező 1–10; az eredmény ≤ 100.
  • Osztás mindig maradék nélkül: hányadosból építve – q (1–10) × d (osztó) = osztandó ≤ 100; a kérdés (q·d) ÷ d = ?, a válasz q.
  • Ismétlés-kerülés: egy állomáson belül nincs két azonos feladat (a szorzásnál N×a és a×N ugyanaz).
  • Táblák keverve: ahol egy állomás több táblát/osztót von be, azok vegyesen jönnek (nem blokkban). Kivétel a B pálya: ott állomásonként EGY tábla (fókuszált).
  • Felolvasás: szorzás „hétszer nyolc. Mennyi?"; osztás „ötvenhat osztva nyolccal. Mennyi?"; felmondás „Mondd fel a hetes szorzótáblát!" (részletes hang-sablonok: spec-hang-es-beszed.html).
  • Válasz elsősorban beszéddel, kisegítő a beírás – mint a többi pályán.

A. pálya — „Szorzódallam" 🎵 (kulcs-pálya)

id: szorzo-dallam  ·  feladat.tipus: szorzotabla-felmondas  ·  szint: felmondós (9 ✨/felmondás)  ·  alcím: „Mondd fel az egész sort – egyszer öt az öt, kétszer öt az tíz…"

A gyerek egy egész táblát mond fel, lentről fölfelé, teljes mondattal. A gép az egészet értékeli (a bontás mintájára): a kimondott eredmények és a sorrend számít.

Generátor-elvárás (a FELADATGENERATOR-hoz)

szorzotabla_felmondas.ujKerdes(cfg):
  N = cfg.tabla ?? veletlen_elem(cfg.tabla_keszlet)
  cel_sor = [1*N, 2*N, ... 10*N]           // amit fel kell mondani, sorrendben
  vissza { csalad:"felmondas", N:N, sorok:cel_sor,
           felolvas:"Mondd fel a "+szo(N)+"-es szorzótáblát! Egyszer "+szo(N)+" az "+szo(N)+"...",
           felmondHelyesE: (kimondott) => a kimondott EREDMÉNYEK sorrendben = cel_sor
                                          (az "egyszer/kétszer/az" kötőszó mindegy) }

szorzas.ujKerdes(cfg):
  N = cfg.szorzo ?? veletlen_elem(cfg.tablak)
  ismételd: a = veletlen(1,10)  amíg (N*a <= 100 ÉS nem_volt_mar(N,a))
  vissza { szoveg:N+" × "+a+" = ?", felolvas:szo(N)+"-szer "+szo(a)+". Mennyi?",
           helyes:N*a, naplo:{tipus:"szorzas", a:N, b:a, helyes:N*a} }

osztas.ujKerdes(cfg):
  d = cfg.oszto ?? veletlen_elem(cfg.osztok)
  ismételd: q = veletlen(1,10)  amíg (d*q <= 100 ÉS nem_volt_mar(d,q))
  osztando = d*q
  vissza { szoveg:osztando+" ÷ "+d+" = ?", felolvas:szo(osztando)+" osztva "+szo(d)+"-vel/-val. Mennyi?",
           helyes:q, naplo:{tipus:"osztas", a:osztando, b:d, helyes:q} }

// B és D: a "szorzas" és "osztas" közül állomásonként/feladatonként keverve (kb. fele-fele);
// B-nél a fókusz-szám N (szorzo), D-nél a tablak halmazból sorsolt N.
